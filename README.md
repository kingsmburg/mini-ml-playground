# mini-ml-playground

Small, reproducible ML experiments for learning and interview demos.

## Goal
One notebook or script per experiment: clear problem → data → model → metric → short takeaway.

## Stack
- Python 3.10+
- scikit-learn
- Jupyter (optional)

## Quick start
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python experiments/01_baseline_classifier.py
```
